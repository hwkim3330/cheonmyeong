# 천명 天命 — 삼국 오픈월드

브라우저에서 하는 툰 셰이딩 삼국지 오픈월드 액션 RPG. 도원결의를 맺은 유비·관우·장비로 시작해,
탁군의 들판과 석림(石林)을 달리고, 봉우리를 기어오르고, 연(비연)을 펴서 날고, 황건적을 무찌른다.
천명 소환으로 조운·제갈량·여포·주유… 새 영웅을 부른다.

**플레이: https://hwkim3330.github.io/cheonmyeong/** (PC, 크롬/엣지 권장) · 허깅페이스: https://huggingface.co/spaces/kimhyunwoo/cheonmyeong

> 원신류(오픈월드 + 캐릭터 수집 + 원소 반응) 장르를 삼국지로 새로 만든 **오리지널 게임**입니다. 다른 게임의
> 에셋·이름·UI는 쓰지 않았고, 모든 모델·텍스처·효과는 이 저장소의 코드로 만들었습니다. 결제는 없습니다 —
> 원보는 게임 안에서만 얻습니다.

## 할 수 있는 것

- **탐험:** 2 km 들판 · 강 · 호수 · 북쪽 산맥 · 수직으로 솟은 석회암 봉우리 숲(계림 같은 석림). 달리기 ·
  질주(Shift) · 점프 · 공중에서 Space로 활공 · 가파른 벽은 향해 걸으면 등반(Space로 도약) · 헤엄. 모두 기력을 쓴다.
- **전투:** 클릭 연속 베기(가까운 적에 달라붙음) · E 전법 · Q 필살(기력이 차면) · Shift 대시(무적 프레임) ·
  1–4 교체. 원소가 적에게 남고 다음 원소와 반응한다: **증발**(화×수) · **감전**(수×뇌, 연쇄·기절) ·
  **폭뢰**(화×뇌, 폭발) · **확산**(풍, 주변으로 퍼뜨림). 히트스톱 · 화면 흔들림 · 데미지 숫자.
- **적:** 황건적 · 창병 · 궁수 · 태평도 술사(바닥 경고 원) · 두목(강인도) · 보스 **지공장군 장보**
  (번개 · 소환 · 광역). 공격은 모두 예고된다.
- **영웅 11명:** 5★ 관우 · 조운 · 여포 · 제갈량 · 주유 / 4★ 유비 · 장비 · 황충 · 초선 · 손상향 · 마초.
  각자 무기(청룡언월도 · 방천화극 · 장팔사모 · 애각창 · 백우선 · 쌍고검 · 궁)와 원소, 전법·필살.
- **천명 소환:** 픽업 배너 두 개, 5★ 0.6% · 74회부터 확률 상승 · 90회 확정 · 픽업 50/50 보장 · 10회마다 4★ 이상.
  중복은 각성(공격력 +). 별이 떨어지는 연출(파랑·보라·금)과 공개 카드. 3★은 병법서(레벨 업 재료).
- **이야기(1장 「황건의 난」):** 도원결의 → 탁현 촌장 → 황건적 초소 → 봉화대 → 서쪽 산채 → 석림의 진영 → 대본영의 장보.
- **모으기:** 천명석(떠 있는 옥, 봉우리 꼭대기에 많다) · 보물상자 · 봉화대(순간이동 · 회복). 자동 저장.

## 조작

| | |
|---|---|
| WASD · 마우스 | 이동 · 시점 (화면을 클릭하면 마우스가 고정된다) |
| Shift | 대시 / 누르고 있으면 질주 |
| Space | 점프 · 공중에서 활공 · 벽에서 도약 |
| 클릭 · E · Q | 공격 · 전법 · 필살 |
| 1–4 | 영웅 교체 |
| F | 조사 · 대화 · 상자 · 봉화대 |
| B · C · M | 천명 소환 · 파티 · 지도 |
| F8 | 그래픽 품질 (낮음 · 보통 · 높음 — 느리면 저절로 내려간다, `?q=0..2`) |

## 어떻게 만들었나

- **셀 셰이딩:** Three.js `MeshToonMaterial`을 고쳐 3단 램프 + 그림자를 보랏빛으로 물들이고, 실루엣에 림 라이트,
  모든 모델에 화면 두께가 일정한 잉크 외곽선(뒷면 껍질). 하늘은 칠한 그라데이션 + fbm 적운, 먼 봉우리는
  수묵처럼 옅은 푸른 안개로.
- **캐릭터:** 부호거리장(SDF)으로 조각해 오프라인에서 굽는다(`tools/bake.ts`). 몸 · 머리카락 가닥 · 한푸 · 넓은 소매 ·
  찰갑 · 견갑 · 망토 · 수염을 원뿔 · 타원체 · 껍질로 쌓고 부드럽게 합친 뒤, 희소 surface nets로 이음매 없는 한 장의
  메시를 뽑아 meshoptimizer로 줄이고 뼈 가중치를 원시 도형에서 물려받는다. 영웅 하나가 스킨드 메시 1장 + 외곽선 1장.
  교령 깃 · 속옷 V · 띠 · 단 · 소매 끝동 · 찰갑 비늘은 바인드 자세 좌표로 프래그먼트 셰이더가 그려 선이 매끈하다.
  얼굴은 캔버스에 그린 애니메 눈(깜빡임), 얼굴 법선은 구로 휘어 애니메식 음영. 절차 애니메이션(걷기 · 질주 · 등반 ·
  수영 · 활공)과 무기별 동작, 머리카락 · 망토 · 띠는 스프링 뼈. `?old`로 예전 조립식 모델을 볼 수 있다.
- **세계:** 1025² 높이장(2 m)이 곧 물리 — 봉우리 벽을 그대로 기어오른다. 청크 LOD 지면 셰이더(풀 · 밭 · 길 · 모래 ·
  빗물 자국 난 석회암), 카메라를 따라다니는 11만 개 풀잎(바람 · 플레이어에 밀림 · 꽃), 깊이로 칠한 물(여울 · 거품 ·
  반짝임), 인스턴싱한 복숭아나무 · 소나무 · 대숲 · 버드나무 · 활엽수, 처마가 휘어 오른 기와집 · 정자 · 패루 · 봉화대 · 목책 진영.
- **초상화:** HUD · 파티 · 소환 카드의 그림은 각 영웅의 3D 모델을 렌더 타깃에 그려 만든다.

```bash
pnpm install && pnpm dev          # http://localhost:5461
node tools/play.mjs shots/p       # 시작 화면 · HUD 스크린샷
node tools/menus.mjs shots/m      # 소환 · 파티 · 지도
node tools/move.mjs shots/mv      # 등반 · 활공
npx tsx tools/bake.ts [id…]       # 캐릭터 모델 굽기 → public/models/
```
